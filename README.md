# Todo List Desktop App

Desktop To-Do List application built with VB.NET Windows Forms and MySQL.

## Features
- Add task
- Edit task
- Delete task
- Mark task as completed
- View task list
- some nice Filters

## Tech Stack
- VB.NET
- Windows Forms
- MySQL
- Visual Studio

## Requirements
- Visual Studio
- .NET
- MySQL Server

## Database Setup
1. Create MySQL database.
2. Import database/todo_list.sql.
3. Configure database connection at Module1.vb.
4. Open TodoList.sln.
5. Run the application.
